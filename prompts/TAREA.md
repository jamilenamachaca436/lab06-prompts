# Tarea: Mi prompt profesional

Elige una funcionalidad sencilla de software que te gustaría construir (por ejemplo: registro de clientes, cálculo de notas o un CRUD de productos) y crea el archivo prompts/TAREA.md. En él vas a documentar cómo llevaste un prompt básico hasta un prompt profesional, iterando al menos tres veces.

## Funcionalidad elegida

Calculo del promedio de Notas 

## Version 1: prompt basico


```text
Crea un programa en Java que calcule e promedio de notas
```
¿Por que?
Busque un programa sencillo 

## Version 2
```text
Eres un programador con experiencia en Java .Crea un programa en Java que calcule e promedio de notas , que  utilice get y set.
```
¿Por que?
Queria que integre get y set en el programa 
¿Que mejoró?
Agrego las funcionalidades como el encapsulamiento ,atributos y metodos get y set.
## Version 3: prompt final

```text

Explicame detalladamente como esta distribuido  y explicame el codigo evitar crear clases innecesarias.
